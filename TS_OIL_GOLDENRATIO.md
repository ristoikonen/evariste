## 1. Native Set Methods in TypeScript

JavaScript and TypeScript include standard built-in methods for all major set operations:

* `.difference(otherSet)`: Returns elements present in the first set but not in the other.
* `.union(otherSet)`: Combines elements from both sets into a new set.
* `.intersection(otherSet)`: Returns elements common to both sets.
* `.symmetricDifference(otherSet)`: Returns elements in either set, but not in both.

```ts
const setA = new Set([1, 2, 3, 4]);
const setB = new Set([3, 4, 5, 6]);

// Set difference (elements in A minus B and B minus A)
const diffA = setA.difference(setB); // Set { 1, 2 }
const diffB = setB.difference(setA); // Set { 5, 6 }
// Other native set operations
const unionSet = setA.union(setB);              // Set { 1, 2, 3, 4, 5, 6 }
const intersectSet = setA.intersection(setB);   // Set { 3, 4 }
const symDiffSet = setA.symmetricDifference(setB); // Set { 1, 2, 5, 6 }

```
